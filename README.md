# MacroZone

**Your personal nutrition and macro tracker.**

MacroZone is a nutrition tracking app built with React Native and Expo. Track your meals and monitor your daily nutritional intake.

## Features

- Track calories, protein, carbohydrates and fats.
- Add and manage meals.
- View your recent meals.
- Delete individual meals or clear all meals.
- Store meal data using Firebase Firestore.
- Firebase anonymous authentication.
- Meal reminders.
- Android and web support.

## Tech Stack

- React Native
- Expo
- TypeScript
- Firebase Authentication
- Cloud Firestore

## Getting Started

Clone the repository:

```bash
git clone https://github.com/25ca12aryan-spec/Macrozone-.git
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npx expo start
```
